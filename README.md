# VOID SIGNAL · 虚空信号

## 安装

Node.js 22.12 或更新版本。

```sh
npm ci
```

## 本地启动

```sh
npm run dev
```

打开终端显示的本地地址。

## Docker 启动

```sh
docker compose up --build
```

打开 http://localhost:8084 。可通过 PORT 环境变量修改端口。

## 元素状态系统

三把武器各自携带一种可组合的元素状态，命中时施加，三种状态可同时存在于同一敌人：

| 武器 | 状态 | 效果 |
| --- | --- | --- |
| 脉冲步枪 | 导电 | 周期性向 150 像素内最近存活敌人跳电，最多 3 跳 |
| 环轨飞刃 | 燃烧 | 每 0.5 秒造成一次周期伤害，持续 3 秒 |
| 新星爆发 | 冰缓 | 移动速度与开火频率降至 55%，持续 2.5 秒 |

设计约束（由 `tests/statuses.test.ts` 守护）：

- **独立可追溯**：每个状态单独保存施加者、传播链（导电）与剩余时间，不合并成单一伤害系数，持续伤害与跳电击杀不会丢失来源，并与直接击杀走同一套掉落逻辑。
- **重复施加只刷新规定部分**：燃烧只刷新剩余时间与下一跳计时（施加者、每跳伤害保留）；冰缓与导电只刷新剩余时间（施加者、传播链、参数保留）。
- **跳电防重复**：同一次脉冲用 `visited` 集合限制，同一轮内不得重复访问同一目标；新感染的导电最早下一脉冲才触发，不会同帧无限扩散；范围内无目标时静默结束，失效传播不入账。
- **暂停不计时**：升级选择与暂停期间 `simulate` 直接返回，状态剩余时间不流逝。
- **死亡续链**：连锁中途目标死亡时，以它死亡瞬间的位置继续寻找下一跳。
- **三类来源记账**：所有伤害经统一漏斗 `applyDamage`，按 `direct`（直接命中）、`periodic`（燃烧周期伤害）、`chain`（跳电）分类；实际扣血以敌人剩余生命为上限，过量伤害不入账，因此三类贡献之和恒等于真实扣血。
